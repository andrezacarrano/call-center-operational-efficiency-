
# 📞 CallMeMaybe — Call Center Operational Efficiency Analysis

This project presents a comprehensive analysis of call center operational efficiency, focusing on identifying bottlenecks, underperforming operators, and opportunities to improve customer service.

---

## 🎯 Project Objective

Evaluate call center operational performance and identify the main factors contributing to inefficiency, based on:

- Missed call rate
- Waiting time
- Inbound vs. outbound call behavior
- Individual operator performance

The analysis aims to support data-driven decisions to improve customer experience and optimize operational performance.

---

## 📊 Key Deliverables

- Development of operational KPIs (call volume, outbound activity rate, average call duration)
- Creation of an **inefficiency score** based on multiple factors
- Identification of the most critical operators
- Comparative analysis of different call types
- Statistical validation of hypotheses through significance testing
- Interactive Tableau dashboard

---

## 📁 Project Structure

- `callmemaybe.ipynb` — Complete analysis (EDA, KPIs, and inefficiency score modeling)
- `telecom_dataset_new.csv` — Main call dataset
- `telecom_clients.csv` — Additional customer data
- `kpi_ops_final.csv` — Consolidated dataset containing operator-level metrics
- `df_calls_exportado_do_notebook.csv`, `df_ops_exportado_do_notebook.csv` — Processed datasets

---

## ▶️ How to Run

1. Open the `callmemaybe.ipynb` notebook in Jupyter Notebook or JupyterLab.
2. Execute the cells sequentially.
3. Make sure all CSV files are located in the same directory as the notebook.

## 📌 Key Insights

- Operational inefficiency is strongly associated with a **high missed call rate** and **long waiting times**.
- Operators with higher inefficiency scores demonstrate significantly lower performance.
- Outbound activity did not show a relevant impact on performance differentiation.

---

## 🚀 Conclusion

The results indicate clear opportunities for operational improvement, particularly in reducing missed calls and optimizing waiting times. These factors are directly related to customer experience and overall service efficiency.
